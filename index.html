              Lier mon compte Santé

              1. Ton code personnel (copié automatiquement) :
              2. Ajoute le raccourci :Ouvrir dans RaccourcisLe lien du raccourci n’est pas encore configuré (voir le guide). Touche « Ajouter le raccourci ».
              3. Colle ton code dans le raccourci : dans l’app Raccourcis, ouvre le raccourci « Synchro pas » (touche les trois points sur sa carte). Le premier bloc s’appelle Texte et contient « COLLE TON CODE ICI ». Touche ce texte, efface-le, fais un appui long puis « Coller », et touche « OK » pour enregistrer.
              4. Lance-le une première fois depuis l’appli : reviens ici, ferme cette fenêtre et touche « Synchroniser mes pas ». Raccourcis s’ouvre et iOS te pose des questions : autoriser la lecture de tes pas dans Santé, et autoriser l’envoi de données vers supabase.co. Réponds « Autoriser » (ou « Toujours autoriser ») à chaque fois. Sans ces autorisations, rien n’est envoyé.
              5. Tu reviens ensuite dans l’appli et tes pas apparaissent. Les fois suivantes, un seul appui sur « Synchroniser mes pas » suffit.

              Si le total reste à 0 : Réglages > Santé > Accès aux données et appareils > Raccourcis, puis autorise « Pas ». Le code sert uniquement à envoyer tes pas, et tu peux délier ton compte à tout moment.
